# Akash — 3D Developer Portfolio

A responsive, single-page portfolio website with a dark visual theme, animated 3D-inspired orb, interactive project cards, skills, and contact section.

## Run locally on your Mac

1. Download and unzip `akash-3d-portfolio.zip`.
2. Open the `akash-3d-portfolio` folder.
3. Double-click `index.html` to open it in your browser.

No Node.js installation or build step is required.

## Publish with GitHub Pages

1. Create a new **public** repository on GitHub named `akash-3d-portfolio`.
2. Do not initialize the repository with a README, license, or `.gitignore` (this folder already contains a README).
3. Open Terminal on your Mac.
4. Navigate to this folder. Example, if it is in Downloads:

   ```bash
   cd ~/Downloads/akash-3d-portfolio
   ```

5. Run these commands one at a time:

   ```bash
   git init
   git add index.html README.md
   git commit -m "Add 3D portfolio website"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/akash-3d-portfolio.git
   git push -u origin main
   ```

   Replace `YOUR-USERNAME` with your actual GitHub username. Use the repository URL GitHub shows you if you chose a different repository name.

6. On GitHub, open the repository → **Settings** → **Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Choose branch **main**, folder **/(root)**, then click **Save**.
9. Wait a minute or two. GitHub Pages will show your published URL, usually:

   `https://YOUR-USERNAME.github.io/akash-3d-portfolio/`
